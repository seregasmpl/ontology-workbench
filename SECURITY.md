# Данные и безопасность

Приложение предназначено для одного пользователя на доверенном компьютере. Оно слушает только `127.0.0.1`; не размещайте его через публичный прокси и не открывайте порт в сеть.

## Ключи

Ключи находятся в памяти процесса либо в системном хранилище секретов Windows, macOS или Secret Service. Небезопасное файловое хранилище не используется как запасной вариант. Ключи не входят в SQLite и штатные экспорты. Не включайте ключи в текст, имена профилей, названия моделей и URL.

Системное хранилище связано с учётной записью операционной системы. Перенос папки приложения на другой компьютер не переносит эти секреты. Для забытого ключа используется отдельное действие в разделе подключений. Отзыв ключа у провайдера выполняет его владелец.

## Передача материалов

Внешний API получает правила, примеры настройки, текст и контекст выбранных записей. Перед запросом показываются адрес получателя и объём операции; требуется подтверждение. Используется HTTPS, кроме явно выбранного локального HTTP-адреса. Переходы на другой адрес через HTTP redirect и прокси из переменных среды отключены.

Отметка закрытого материала не является шифрованием или системой разграничения доступа. Закрытая запись исключена из экспорта по умолчанию, но может входить в явно подтверждённый API-запрос. Передача должна соответствовать правам пользователя на материал и условиям провайдера.

## Локальные файлы

База SQLite не зашифрована. Системный администратор, вредоносная программа или другой процесс с доступом к файлам пользователя может прочитать проект. Защитите учётную запись и диск средствами ОС. Не синхронизируйте папку `data` в публичные репозитории и общедоступные облачные каталоги.

При резервном копировании сначала завершите работу приложения и копируйте всю папку данных. Два экземпляра с одной папкой блокируются, чтобы один процесс не сбрасывал задания другого.

## Экспорт и отчёты об ошибках

Перед публикацией экспорта просмотрите исходные тексты, доказательные цитаты, идентификаторы и собственные определения. Свободно введённые поля могут содержать чувствительные сведения независимо от настроек программы. Не прикладывайте к публичным issue реальные базы, ключи или закрытые материалы; используйте минимальные синтетические примеры.

Случайно опубликованный ключ нужно отозвать у провайдера, а не только удалить из последней версии файла. Сообщая об уязвимости, не публикуйте рабочие секреты и не испытывайте её на чужих данных.

## Проверки версии

Есть ограничения Host/Origin, локальный токен сеанса, запрет встраивания страницы, проверка схем ответов и точного совпадения доказательных фрагментов. Эти меры не являются независимым аудитом безопасности. Покрытие и непроверенные сценарии перечислены в `QA.md`.
